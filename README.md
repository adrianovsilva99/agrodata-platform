# AgroData Platform

[🇺🇸 English](#-en-us) | [🇧🇷 Português](#-pt-br)

## 🇺🇸 EN-US

Portfolio project focused on Data Engineering.

The goal is to build a data platform that integrates public weather, economic, and agricultural production data sources, applying concepts such as data ingestion, transformation, data quality, dimensional modeling, and orchestration.

### Status

Under development.

### Initial Stack

* Python
* PostgreSQL
* Docker
* Docker Compose

### Initial Roadmap

* [x] Initial project structure
* [x] Local PostgreSQL environment with Docker
* [x] Python connection to PostgreSQL
* [ ] Weather data ingestion
* [ ] Orchestration with Airflow
* [ ] Transformations with dbt
* [ ] Data Warehouse
* [ ] Analytics layer
