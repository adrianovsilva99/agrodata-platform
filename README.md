# AgroData Platform

Projeto de portfólio focado em Engenharia de Dados.

A proposta é construir uma plataforma de dados que integre fontes públicas de clima, economia e produção agrícola, aplicando conceitos de ingestão, transformação, qualidade de dados, modelagem dimensional e orquestração.

## Status

Em desenvolvimento.

### Stack inicial

- Python
- PostgreSQL
- Docker
- Docker Compose
